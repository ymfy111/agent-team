## 核心架构口径

1. 当前阶段不直接实现完整状态机，避免过度设计。
2. 第一阶段：Agent-led Task List（主智能体负责计划、拆任务、维护清单）。
3. 系统负责持久化计划、任务单、执行反馈、审查记录和待决策事项。
4. 结构化 Markdown = YAML Front Matter + 正文 + 标记区块 + 可选 JSONL 事件。
5. 四阶段演进：Agent-led Task List → Guarded Task Flow → State-machine → Factory Runtime。

## 目录使用规则

- `specs/`：需求规格、系统设计。
- `plans/`：实施路线图、阶段计划。
- `tasks/`：WBS、开发任务流、执行清单。
- `templates/`：结构化 Markdown 模板。
- `decisions/`：ADR（架构决策记录）。
- `changes/`：版本变更说明。
- `guides/`：执行流程指南。
- `prototypes/`：HTML 原型与视觉素材。
