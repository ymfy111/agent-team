# DEV-TASKFLOW v0.6.33

## 目标

在 v0.6.33.33 原型与文档收口后，进入真实开发前的 P0/P1 任务流建议。

## P0 任务流建议

### P0-01 基础数据模型与 Mock API

目标：建立项目、团队、员工、岗位、任务单、待决策的最小数据模型。  
产物：后端 Mock API / 前端 Mock 数据服务 / 类型定义。  
验收：总览、项目、团队、待决策、员工页可从统一数据源读取。

### P0-02 任务单最小闭环

目标：支持计划、执行、审查、待决策、完成的最小状态。  
产物：TaskTicket、ReviewRecord、DecisionItem 最小模型。  
验收：一个项目可以走通任务单闭环。

### P0-03 页面工程化落地

目标：将当前 HTML 原型拆入真实前端工程。  
产物：页面组件、路由、状态管理、Mock API 接入。  
验收：首页、项目健康、团队详情、待决策、员工页可运行。

### P0-04 待决策恢复流转

目标：用户处理待决策后，任务能恢复执行或进入审查/完成。  
产物：待决策处理动作、恢复流转逻辑。  
验收：至少一个待决策场景可闭环。

## P1 任务流建议

### P1-01 Runtime 绑定模型

目标：补充 RuntimeHost / RuntimeNode / WorkerRuntimeBinding。  
验收：员工页运行绑定信息可来自数据模型。

### P1-02 技能快照与岗位映射

目标：实现 TemplateSkillMapping / SkillSnapshot。  
验收：员工启用时可生成岗位技能快照。

### P1-03 多团队并行与冲突处理

目标：从串行任务流演进到多团队并行执行。  
验收：多个团队可同时推进不同任务，冲突进入待决策或审查队列。

### P1-04 Agent Runtime 适配探索

目标：评估 OpenCode / Claude Code / Codex 接入方式。  
验收：形成 Runtime 适配设计和最小调用验证。
